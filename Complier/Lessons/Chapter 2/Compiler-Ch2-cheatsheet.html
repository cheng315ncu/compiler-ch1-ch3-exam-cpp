2｜Token：kind 與實際字串 PPT 3–5、12–14

Explain what a token / lexeme is.

A token is a lexical unit with a type and, when needed, a value. Its lexeme is the actual character sequence in the source.

b：type = id，value = "b"。3.2：type = fnum，value = "3.2"。Parser 選規則看 type，符號表／產碼需要 value。

4｜RE 與 CFG 的分工

What is the difference between a regular expression and a context-free grammar?

In this compiler, regular expressions specify the character patterns of tokens. A context-free grammar specifies how tokens form declarations, expressions, statements, and programs.

terminal：不能再改寫，本章是 token kinds。
non-terminal：可依 production 改寫。
production：A → α，將 LHS 的 A 換成 RHS 的 α。
start symbol：本章為 Prog。
λ / ε：空字串，不消耗任何 token。
$：end-of-input marker，與 λ 不同。

Why are scanning and parsing separate?

Scanning handles character-level patterns; parsing handles token-level structure. This separation simplifies the grammar and lets the parser operate on token types.

8｜Predict 怎麼算、怎麼解釋？

What is a predict set? Why must the sets be disjoint?

A predict set contains the lookahead tokens for selecting a production. For predictive parsing with one token of lookahead, alternatives of the same nonterminal must have disjoint predict sets so that the choice is unique.

  1. RHS 第一個是 terminal t → {t}。
  2. 第一個是 non-terminal → 找它能導出的第一個 token；若可為空，繼續看後面符號。
  3. 整個 RHS 可為 λ → 加入 LHS 後面能接的 token。
補充公式（FIRST / FOLLOW）：
Predict(A → α) = FIRST(α) − {λ}；
若 α ⇒* λ，再聯集 FOLLOW(A)。
這是推算工具，Ch2 先用口語說明。

Stmts → Stmt Stmts：Stmt 可由 id 或 print 開始，故 {id, print}。
Stmts → λ：Prog 裡 Stmts 後面是 $，故 {$}。
Expr → λ：後面是下一個 Stmt 或程式結尾，故 {id, print, $}。

λ 分支不能寫「前面分支都不是就 return」。Expr 遇到 inum 並不合法；λ 不表示吞掉未知輸入。

9｜Recursive descent 的程序模板

Recursive descent uses one procedure per nonterminal. It selects a production using lookahead, matches terminals, and calls procedures for nonterminals in RHS order.

教材虛擬碼整理（不建 AST 的辨識版）
STMT():
  if peek() == id:
    match(id); match(assign)
    VAL(); EXPR()
  else if peek() == print:
    match(print); match(id)
  else: error()

STMTS():
  if peek() in {id, print}:
    STMT(); STMTS()
  else if peek() == $: return   // λ
  else: error()

MATCH(t)：確認 lookahead 為 t，成功才消耗；不符即 syntax error。LL(1)：由左到右讀輸入（L），最左推導（L），看 1 個 token。

What if one lookahead cannot select a unique rule?

Rewrite the grammar or use more lookahead, if sufficient. Overlapping predict sets prevent a unique LL(1) choice; they do not by themselves prove ambiguity.

Recursive descent 也可能使用回溯；本章採 predict set 選分支。不能推論所有文法都可藉增加 lookahead 解決。

12｜畫 parse tree 的檢查法

  1. 根為 Prog，孩子 Dcls、Stmts、$。
  2. 每次展開完整照 RHS 左到右放孩子。
  3. Dcls / Stmts 遞迴串接，最後 λ 收尾。
  4. 指定式：id、assign、Val、Expr。
  5. 葉由左到右忽略 λ，等於完整 token 串。
不要提前變成 AST：parse tree 的 plus 是 Expr 底下的 terminal 葉；AST 的 plus 才是兩個運算元的父節點。嚴格文法樹中 Val 下保留 inum／id 這層。

14｜遞迴方向不等於運算結合性 PPT 28、42；補充辨析

15｜Symbol table PPT 29–33

What does the symbol table store? Why 23 entries?

The ac symbol table maps each identifier to integer, float, or unused (null). There are 23 possible identifiers: the 26 lowercase letters excluding the reserved letters f, i, and p.

動作規則
初始化全部設 null（尚未宣告）
EnterSymbol(name,type)null 才填入；已有型別 → duplicate declaration
LookupSymbol(name)回傳型別；null 代表未宣告
範例 f b / i ab→float、a→integer；其他 21 項 null
null 是 unused 狀態，不是第三種運算型別。表記錄型別，不是 a=5、b=8.2 這些執行期值。C 補充實作用 26 格陣列方便索引，課本仍是 23 個可用名稱。

18｜Semantic action：執行或記錄？ PPT 25–27

What happens after parsing a = 5?

An interpreter may execute the assignment immediately. In this chapter's compiler, the semantic action records the assignment in an AST for later analysis and code generation.

走完 id assign Val Expr 已知道目標和 RHS，可建 assign 節點。本章先建 AST，再檢查、產碼；不是所有 compiler 都必須如此排程。

22｜dc 指令的易混處

  • sr 會 pop；lr 只讀暫存器、push 副本。
  • p 印出 top，不 pop；用 si 清理。
  • i 是 ac 保留字、不能當變數名，作 dc 垃圾暫存器不會覆蓋使用者變數。
  • 5 k：push 5，再由 k pop 5 作 scale；不是把原有 top 改成 5。
  • 0 k 不把已存入暫存器的 8.2 變成 8。
教材模型與 dc 行為：k 設定 scale，並非硬體的 int→float 指令。dc 的加減小數位由運算元決定，不能說 5 k 使所有輸出固定五位；考產碼仍照 Fig 2.14。

24｜減法：一定要分左右

L R - 計算 L − R；先 pop 的是右運算元 R，第二個 pop 才是 L。

左結合：(100 - 30) - 1
100 30 - 1 -       → 69

右結合：100 - (30 - 1)
100 30 1 - -       → 71

x=x-30 產碼：lx 30 - sx 0 k。不是 30 lx -，也不應先 sx 才計算 RHS。

Why is si emitted after p?

The dc print command leaves the value on the stack. The generated si pops it into the unused register i, restoring the stack for subsequent statements.

(c) 可選的有號指數

教材原解答（照錄結構）：

inum  [0-9]+ e -? [0-9]+
fnum  [0-9] . [0-9]+ e -? [0-9]+
與題意有三個落差：① 指數變必填；② 只收負號、漏正號；③ fnum 小數點前只有一位。「依題意擴充」時應補齊。

依題意補充：接受原數字及指數形式；帶指數者歸 fnum（123e-22 不一定是整數）。

inum  [0-9]+
fnum  [0-9]+\.[0-9]+(e[+-]?[0-9]+)?
      | [0-9]+e[+-]?[0-9]+

e 依題目小寫；要 E 另明定 [eE]。流程：數字 → 可選小數部分 → 可選 e → 可選 +/− → 至少一位指數數字。

應接受（補充規則）非完整數字格式
5、3.2、1.0e10
123e-22、123.4e+5		1e、1e+、3.e2、.5

不完整指數依明定 scanner 規則報 malformed number，或退回較短 token 由後續階段拒絕；RE 本身未決定所有錯誤回復策略。

Extension answer：Update both the token patterns and the scanner. Recognize the optional exponent and its sign, require exponent digits, and preserve characters that belong to the next token.

後端：dc 不直接接受科學記號；須轉成可輸出的十進位寫法，不能直接 EMIT 1e10。
