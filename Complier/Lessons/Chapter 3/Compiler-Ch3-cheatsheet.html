(bc)*d：先 b 串 c → 對 bc 加 * → 再串 d。測 d ✓、bcd ✓、λ ✗、bc ✗。

交卷檢查：所有邊有 label；只把完整表達式出口標接受。若內層 A 含 λ，A+ 仍可收 λ。

F5｜給短程式，畫 AST 4 棵完整樹 p.4

① 確認語言及結合性。② 按來源順序列敘述。③ 指定句先畫 assign（目標，RHS）。④ RHS 按括號／優先序／結合性遞迴拆。⑤ 不畫純語法包裝，保留識別字與常數。

一般 C-like x=a+b*c;：
assign(x, plus(a, times(b,c)))。
整句根=assign，RHS 根=plus，不可把 + 畫在 * 的下面。

以還原括號式驗算。題目要 AST，就畫節點與邊；未要求時不先常數摺疊。教材 ac 的右結合差異見 p.4。

1｜Why use a context-free grammar instead of others? Quiz 2；Ch3 PPT 51–52＋補充

可直接寫：Context-free grammars can describe recursive and nested syntax, such as balanced parentheses, which regular grammars cannot express in general. They offer a useful balance between expressive power and practical parsing. More powerful grammar classes make general parsing harder, while declaration and type constraints are usually checked separately during semantic analysis.

中文抓分：① 足以表達無上限巢狀／遞迴結構；② 比 regular grammar／RE 強；③ 比更強文法容易設計實用 parser；④ 語法與型別／宣告檢查分工。不要只寫「CFG 比較快」，RE 的 DFA 掃描通常反而很有效率。

規格擅長什麼作答時的界限
RE / regular grammaridentifier、number、keyword 等 token 形狀有限狀態；不能一般性地配對任意深度括號
CFGexpression、statement、program 的遞迴結構A → α：左側只有一個 nonterminal；不保證無歧義或 LL(1)
Context-sensitive / unrestricted grammar可描述更廣的字串限制一般剖析更複雜；日常 compiler 多將相關限制交 semantic analysis
最短版：CFGs express nested program structure beyond regular languages and support practical parsing; semantic analysis handles declaration and type constraints.

2｜Scanner / Parser / Semantics

階段輸入 → 輸出／任務
Scanner / lexercharacters → tokens；RE 辨認詞素
Parsertokens → syntax structure / AST；依 CFG

The scanner groups characters into tokens. The parser checks token structure using a CFG and builds a syntax representation. Semantic analysis checks meaning-related constraints such as declarations and types.

建 scanner：RE → NFA → DFA → table／code。
跑 scanner：source characters → tokens。
兩條流程不可倒混；scanner 不負責畫 AST。

3｜Token / Lexeme / Attribute PPT 3、31

A token has a type and, when needed, an attribute. The lexeme is the actual source character sequence matched by the token pattern.

count：type=ID，lexeme="count"，attribute 可為符號表索引。007：lexeme="007"，數值 attribute 可為 7。

Pattern 是規格；lexeme 是實際字串；token type 是 parser 用來分類的名稱。不同 lexemes 可屬同一 type。

4｜CFG 強在哪？一個可寫的例子

令 L = { anbn | n ≥ 0 }，CFG：

S → aSb | λ

S ⇒ aSb ⇒ aaSbb ⇒ aaaSbbb ⇒ aaabbb。每次多一個 a，同時多一個 b；λ 結束，a 都在 b 之前。

有限 DFA 反證：若有 m 個狀態，讀 a⁰、a¹、…、aᵐ 後至少兩個字首 aⁱ、aʲ（i<j）到同一狀態。再接 bⁱ，DFA 必須同判；但 aⁱbⁱ 應收、aʲbⁱ 應拒，矛盾。

不要寫：「aaabbb 不是 regular」。單一字串可直接用 RE aaabbb。不能表達的是任意 n 的整個等量語言。

括號例：S → (S)S | λ 可表達平衡括號。CFG 的「context-free」指改寫 A 不需看左右上下文，不是程式不用考慮 scope。

6｜四步畫樹＋一個驗算 Ch2 PPT 27–28、39–42＋自編例題

① 分敘述：program / block 依來源順序接 declaration、assignment、print 等。② 找最外層：如 x=E 先畫 assign，左目標、右 RHS。③ 遞迴分解：先按括號、再優先序、再結合性決定 expression 的根。④ 保留：operators、識別字、常數、必要的敘述結構；省略純語法包裝與分隔符。⑤ 驗算：由樹還原括號式，檢查左右、先後與題目相符。

An AST represents the essential syntactic structure using operators and operands. It omits grammar-only nodes and punctuation while preserving precedence, associativity, and statement order.

第二次小考未附實際短程式。下方 A/B 是一般 C-like 補充練習，不是原小考答案；教材 ac 沒有乘法、括號或分號。先辨認題目採哪套語言。

7｜A：x = a + b * c;

RHS 的根是 +：因 * 優先於 +，b*c 作一個子樹。整句的根仍是 assign。

assign(id(x),
       plus(id(a), times(id(b), id(c))))

上式是樹的文字記法；要求畫樹時，畫節點與邊。葉標 a 或 id(a) 須一致。

8｜B：x = (a + b) * c;

RHS 的根改成 *：括號強制先加；AST 通常不畫「(」「)」節點，樹形本身保留分組。

assign(id(x),
       times(plus(id(a), id(b)), id(c)))

Expr、Term、Factor、分號、λ 屬 parse tree 的語法細節。

9｜結合性：同優先序時怎麼拆？

一般 C 減法左結合：x-30-1 → (x-30)-1；最外層是最後一個 −。

x=100 時左樹得 69；右樹 x-(30-1) 得 71。左右運算元不能交換。

一般 C 指定右結合：x=y=z → assign(x,assign(y,z))。一元負號 -x 畫 neg(x)，與 binary minus(L,R) 分開。

右遞迴文法不必強迫右結合 AST；semantic actions 可累積左子樹。以題目指定的語意／教材圖為準。

重繪 Ch2 p.42 的樹形；補明 declaration／token 名稱。

11｜容易失分：AST ≠ Parse Tree ≠ Decorated AST

表示保留什麼作答提醒

12｜RE 是語言：一個字串集合

A regular expression specifies a regular language: the set of strings that match its pattern. A finite automaton recognizes that language.

Σ：有限字母表；Σ*：Σ 上所有有限長字串。λ / ε：空字串，|λ|=0。∅：空集合，沒有任何字串。L(λ)={λ} ≠ L(∅)=∅；教材用 0 表空集合，不是 literal "0"。

形式語意／展開例與陷阱
A | BL(A) ∪ L(B)；選任一支a|bc 接受 a 或 bc，不接受 abc
AB先 A 再 B；{xy | x∈L(A), y∈L(B)}一般 AB ≠ BA；Aλ=λA=A
A*0 次以上；λ | A | AA | …一定含 λ；∅*={λ}
A+1 次以上；AA*若 A 自己含 λ，A+ 仍可能含 λ
A?0 或 1 次；A | λ(ab)? 接受 λ 或 ab
Aᵏ串接恰 k 次；A⁰=λ(ab)² 是 abab
Not(C)字元集合 Σ\C，C⊆Σ只排除單一字元集合；非任意語言補集

優先序：分組 (…) → postfix * + ? → 串接 → |。Literal：要匹配字面 *、+、.，依工具 syntax 跳脫或用字元類別。[.] 是字面點；多數 regex 工具的 . 是 wildcard，是否含換行取決於 dialect／設定。

13｜最常見的分組判斷

RE整串可接受整串不可接受
ab*a, ab, abb, …λ, b, abab
(ab)*λ, ab, abab, …a, abb
(abc+)+abc, abcc, abcabcλ, ab, abbc
(a|b)*abbabb, aabb, babb, ababbλ, ab, abba

不要看字元各自出現過就說合法。(abc+)+ 每塊都是一個 a、一個 b、至少一個 c，然後整塊至少一次。

A∅=∅A=∅；A|∅=A。空字串是串接的單位元，空集合是會讓串接全空的集合。

14｜Identifier：本章特有規格 p.15、32

L = [A-Za-z]    D = [0-9]
L(L|D)*(_(L|D)+)*

讀法：字母開頭；後接任意字母／數字；每個底線後至少一個字母／數字。允許 foo_2_bar，拒 _foo、foo_、foo__bar。

底線不是任意可放；[A-Za-z_][A-Za-z0-9_]* 是另一套常見 ID 規格，不能代替本頁教材。

15｜格式符合不代表語意正確

p.16 日期規格允許年 1900–2099、月 01–12、日 01–31，所以 2001-02-31 形狀符合，日曆不合法。兩個分隔符獨立，2001/02-03 也符合。

字串 "[^"\r\n]*" 禁 quote／CR／LF，但沒定義跳脫引號；不能當完整 C string 規格。

① 整個 exponent 可省略：(e…)?。② exponent 內符號可省略：[+-]?。e 後數字始終至少一位。沿用 ac：小數點兩側必須有 digit。

30｜Why correct? Why terminate? 英文說理題＋補充不變量

Initially, epsilon closure gives every NFA state reachable without input. After each symbol, move collects all symbol transitions and closure adds every epsilon-reachable state. Thus the subset always equals the possible NFA positions after that prefix. Both automata accept exactly when this subset intersects the NFA accepting set.

終止：n 個 NFA states 至多有 2n 個子集；只處理可達集合，且每個至多一次。2n 是上限，不是每題一定生成的個數。此例 5 個 NFA state → 5 個可達 DFA state。

38｜英文短答：Definition / Difference

What is epsilon closure?

It is the set of states reachable from a given set through zero or more epsilon transitions, including the original states.

Is an NFA more powerful than a DFA?

No. Both recognize regular languages. Subset construction converts an NFA into an equivalent DFA.

What is a dead state?

It is a non-accepting state from which no accepting state is reachable. The empty subset in subset construction is a sink that loops on every input symbol.

40｜英文短答：Why / Scenario

Why convert RE to NFA and then to DFA?

NFAs are easy to build compositionally from regular expressions. A DFA then supports deterministic scanning with one next state per input symbol.

When is a subset accepting?

When it contains at least one accepting NFA state; it does not require all member states to be accepting.

Why must a scanner remember the last acceptance?

A longer candidate may fail after a shorter valid token prefix. Remembering the last accepting position allows the scanner to return the longest valid prefix.
