HTML parser 與標籤配對

契約：stdin 全部內容為一份 HTML fragment。預設輸出 VALID／INVALID，兩種判定均 exit 0。--tokens 只分詞；--tree 配對後輸出縮排樹；--text 配對後串接原始 TEXT，不自動加末尾換行。非 check 模式遇錯時 stdout 為空、stderr 診斷、exit 1。

範圍：考試子集：ASCII 名稱轉小寫；boolean、單雙引號／無引號屬性；短 DOCTYPE html；13 個 void elements；script/style/title/textarea 讀到匹配結束標籤。一般元素必須顯式關閉；<custom/> 依本版類 XML 政策關閉。沒有瀏覽器錯誤修復、可省略 end tag、namespace/template 特殊 DOM、完整 script tokenizer、DTD、內容模型或 entity 解碼；註解以第一個 --> 結束；名稱限字母／_／: 開頭，後接字母數字／-／_／:。允許空 fragment／多個根及任意 DOCTYPE 位置。

考場改法：只檢查 tag 配對時保留 START/END 的 stack。若一行一案，把 main 的整份讀取改為外層 getline，但跨行 HTML 必須仍當一案。tag 數／深度在 parse 的 push/pop 更新，路徑由 nodes.children 走訪。VALID/INVALID 字樣只改 main。

運算式 AST、後序式與求值

契約：每行一個完整運算式，無案例數。預設每行印空白分隔的 postfix；--ast 每行印一棵 S-expression；--eval 只接受常數，印 15 位有效數字。空白行非法，完全空的輸入表示零案例。任一案例失敗不發出任何暫存輸出，stderr 診斷、exit 1。

範圍：支援 + - * /、括號、一元正負、小數與 e/E。ID 採 [A-Za-z_][A-Za-z_0-9]*，只供 AST/postfix；求值沒有變數環境。沒有 =、%、^、函式、隱含乘法。long double 拒絕零除／非有限值，但非精確有理數，顯示會捨入。

考場改法：只畫 AST 用 --ast；只求值把 main 預設改 --eval。求值變數要在 evaluate 葉節點加入符號表。新增 ^ 必須另定右結合及相對 unary minus 的優先序，不能只加入運算子字串。

// One expression per line; shunting yard builds AST, postfix, or evaluates constants.// Grammar: expr=term{(+|-)term}; term=unary{(*|/)unary}; unary=(+|-)unary|primary.#include <cmath>#include <iomanip>#include <iostream>#include <locale>#include <sstream>#include <stdexcept>#include <string>#include <utility>#include <vector>bool digit(char c) { return c >= '0' && c <= '9'; }bool letter(char c) { return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || c == '_'; }bool space(char c) { return c == ' ' || c == '\t' || c == '\r' || c == '\n'; }int priority(char op) { return op == '~' || op == '`' ? 3 : op == '*' || op == '/' ? 2 : 1; }struct Node { std::string value; int left = -1, right = -1; };struct Expression {    std::vector<Node> nodes;    int root = -1;    explicit Expression(const std::string& s) {        std::vector<int> values;        std::vector<char> ops;        const auto apply = [&] {            const char op = ops.back(); ops.pop_back();            const bool unary = op == '~' || op == '`';            if (values.size() < (unary ? 1u : 2u)) throw std::runtime_error("missing operand");            const int right = values.back(); values.pop_back();            int left = -1;            if (!unary) { left = values.back(); values.pop_back(); }            nodes.push_back({op == '~' ? Scanner、註解與 longest match

契約：stdin 整份來源到 EOF。每行 KIND "lexeme"，std::quoted 轉義引號／反斜線，末行 EOF。KW／ID／NUM／STRING／CHAR／OP／PUNCT；空白與 //、/* */ 不回傳 token。任何錯誤使 stdout 為空、stderr 診斷、exit 1。

考場改法：keyword 改 keywords；多字元運算子改 ops 並維持長到短。若題目要求教材 ID，須在 ID 後驗證每個 _ 後至少一個 alnum、首字元為字母。要位置時集中於游標前進更新行欄，CRLF 算一次換行。
