2｜程式骨架：Scanner ＋ Recursive Descent（照抄改 token）

A. 整份讀入版 Scanner（Parser 題通用）

enum Token { NUM, ID, PLUS, LPR, RPR, END, INVALID };
string src; size_t pos = 0, start = 0; Token token;
// [start, pos) 是目前 token 的原字串
void next_token() {
    while (pos < src.size() && isspace((unsigned char)src[pos])) ++pos;
    start = pos;
    if (pos == src.size()) { token = END; return; }
    unsigned char c = src[pos++];
    if (isdigit(c)) {                 // NUM -> 0 | [1-9][0-9]*
        if (c != '0') while (pos < src.size() && isdigit((unsigned char)src[pos])) ++pos;
        token = NUM;
    } else if (isalpha(c) || c == '_') {   // ID
        while (pos < src.size() && (isalnum((unsigned char)src[pos]) || src[pos] == '_')) ++pos;
        token = ID;
    } else if (c == '+') token = PLUS;
    else if (c == '(') token = LPR;
    else if (c == ')') token = RPR;
    else token = INVALID;
}
bool match(Token t) { if (token != t) return false; next_token(); return true; }

3｜文法、FIRST／FOLLOW／PREDICT、LL(1)

算法（手算與 08 ll1.cpp 同一套）

  • FIRST(α)：α 第一個 terminal；若第一個符號可為 λ，繼續看下一個；全部可為 λ 則含 λ。
  • FOLLOW(A)：start 含 $；B → α A β 把 FIRST(β)−λ 加入 FOLLOW(A)；β 可為 λ（或 A 在尾端）時再加 FOLLOW(B)。反覆到沒有變化。
  • PREDICT(A → α) = FIRST(α) − {λ}；若 α ⇒* λ，再聯集 FOLLOW(A)。
  • LL(1)：同一 nonterminal 的各條 PREDICT 兩兩不相交。表格 M[A, t] 一格多條 = conflict。重疊不等於有歧義。
  • Predictive stack：$ S 入棧；頂端 terminal 要等於 lookahead；nonterminal 查表後 RHS 反序 push（S → a S 先 push S 再 push a）。

例：S → a S | λ：FIRST(S)={a, λ}、FOLLOW(S)={$}、PREDICT(S→λ)={$}。A → B C 且 C 可為 λ：FOLLOW(A) ⊆ FOLLOW(B)。

RE vs CFG；為何用 CFG

RE 描述 token 形狀（有限狀態）；CFG 描述遞迴、任意深度巢狀的語法（如 S → (S)S | λ、S → aSb | λ 即 aⁿbⁿ，DFA 做不到）。宣告／型別不由 CFG 檢查，交給語意分析。

Context-free grammars can describe recursive and nested syntax, such as balanced parentheses, beyond regular expressions. Their productions give structure for parsing and AST construction; declaration and type constraints are checked separately.

4｜Scanner、RE、NFA → DFA

Scanner 規則

  • Maximal munch：取最長合法前綴；同長才比規則先後（keyword 規則在 ID 前）。float→FLOAT、floatx→ID、>>= 一個 token。
  • 長候選失敗要退回最後接受位置（只有 a、abc 兩種 token，輸入 abx → 回 a，從 b 續掃）。
  • 整串辨識（recognize）≠ 切 token（tokenize）：12e 不是完整 NUM，但 scanner 可能切 NUM(12) ID(e)。
  • 負號是 MINUS，不併進數字；007：ac 是一個 inum，ScannerTest 是 NUM 0 ×3。
  • quoted literal 內的 // 不是註解。

RE → NFA（Thompson）

  • literal：s ─a→ f；λ：s ─λ→ f。
  • A|B：新 start λ 分到 A、B；兩出口 λ 到新 final。
  • AB：A 出口 λ 接 B 入口（只讀完 A 不算接受）。
  • A*：新 s→f 的零次旁路＋A 出口回 A 入口的重複邊。A+：去掉零次旁路。A?：只有旁路。
  • 只把整體出口標接受；每條邊寫字元或 λ；標 start、F、Σ。

NFA → DFA（子集構造）

S₀ = close({q₀})；δD(S,c) = close(move(S,c))；S 接受 ⇔ S ∩ F ≠ ∅

  1. close 包含自己，沿 λ 走到固定點（不是只走一步）。
  2. 每個新集合依字母表順序算每個字元；相同集合沿用名稱（順序無關）。
  3. ∅ 是拒絕 sink，完整表要列（若可達）。
  4. n 個 NFA state 最多 2ⁿ 個子集，只列可達的。
  5. 驗算：λ、最短接受、近似錯例（讀完才判）。

最小化：先分 {接受}/{拒絕}，再依各字元後繼所屬組反覆細分到不變。「都拒絕」不代表可合併。

小考英文短答

Compiler vs interpreter. A compiler translates a source program into a target program, which is executed later. An interpreter executes the source program or its intermediate representation with input data and directly produces results.

Token. A token is a basic lexical unit recognized by the scanner, such as a keyword, identifier, literal, operator, or punctuation. It has a kind and may carry an attribute; the actual characters form its lexeme.

Win x86 → Linux x86? Not necessarily. The executable format, OS interfaces, ABI, and libraries differ, so the binary cannot run directly. Portable C source can be recompiled for Linux; Windows-specific code must be ported.

javac for ARM. Use a C cross-compiler on x86 that targets ARM to compile javac's C source, link ARM libraries, and move the executable to the device (or build natively on ARM). javac still emits bytecode.

Grammatical vs semantic error. A syntax error violates the grammar, such as a missing operand or unmatched parenthesis. A semantic error violates meaning rules with valid syntax, such as an undeclared identifier or a type mismatch.

Why CFG? 見第 3 節方框。

NFA vs DFA. A DFA has one next state per state and symbol; an NFA may have several choices and epsilon moves. Both recognize regular languages; subset construction converts an NFA into an equivalent DFA.

Epsilon closure. The set of states reachable from a set through zero or more epsilon transitions, including the original states.

Why last acceptance? A longer candidate may fail after a shorter valid prefix; remembering the last accepting position lets the scanner return the longest valid token.

Parse tree vs AST. A parse tree records the full grammatical derivation; an AST omits grammar-only details and keeps the operations and operands needed later.

答題句型：Explain → 定義＋輸入輸出＋小例；Difference → “X …, whereas Y …”；Is it valid → lexically／syntactically／semantically 逐層說。
