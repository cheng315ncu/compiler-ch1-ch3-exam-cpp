01 HTML 標籤配對

題目內容

歷屆 HTML parser 是使用者提供的線索，未提供原考卷；以下是完整模擬題。

請撰寫程式讀入一份 HTML fragment，判斷所有非 void、非自閉合元素是否正確巢狀。開始標籤必須依相反順序關閉；END 名稱須與最內層未關閉元素相同。名稱不分 ASCII 大小寫。支援 boolean、單雙引號與無引號屬性、註解、短 DOCTYPE html；script/style/textarea/title 內容讀到匹配 END。多個根元素與空 fragment 均合法。

輸入規格
stdin 全部內容到 EOF 是一個案例，可能跨行。普通元素必須顯式關閉；本模擬題將 <x/> 視為自閉合。無額外案例數 T。
輸出規格
合法印 VALID，否則印 INVALID，每次只印一行；這兩種分類都正常結束。
限制與適用範圍
不是完整 browser DOM：不恢復錯誤、不省略 end tag、不解碼 entity、不檢查內容模型。這裡的「合法」指指定子集。

Code 檔案名稱：html_check.cpp （exam/short/html_check.cpp）

g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic -Werror html_check.cpp -o main
./main < input.txt

邏輯與手動追蹤

START 入 stack；END 必須匹配頂端才 pop；EOF 時 stack 必須空。void 與自閉合標籤不入 stack；屬性引號內的 > 不結束標籤，註解與 raw text 另行跳過。

  • <a><b>x</b></a>：[] → [a] → [a,b] → [a] → []，接受。
  • <a><b></a></b>：讀 </a> 時 top 是 b，立即拒絕。
  • <p title="a>b">x</p>：引號中的 > 不切開 tag。
  • <p a=x/> 沒有關 p；<p a=x /> 則已自閉合。

02 遞迴下降運算式

題目內容

Ch2 recursive descent / AST 的延伸模擬題；乘除、括號與一元正負不在原 ac 文法。

請讀入每行運算式，依通常優先序計算結果，或依題目指定改為 postfix / AST。一元正負優先於乘除，乘除優先於加減；同級二元左結合。括號可覆寫優先序。number 允許 .5、10.、十進位小數及 e/E 科學記號；ID 符合 [A-Za-z_][A-Za-z_0-9]*。求值模式不允許變數。

輸入規格
每行一個完整運算式到 EOF，沒有 T；完全空輸入是零案例，但空白行本身是非法運算式。
輸出規格
預設 eval：每行印 15 位有效數字的 long double 結果。postfix：以一個空白分隔 token。一元正負用 pos/neg。ast：印前序括號表示。
限制與適用範圍
嵌套括號／一元鏈最多 256；不支援 %、^、函式或隱含乘法。非法字元、缺 operand、零除、非有限值：stdout 空、stderr 訊息、exit 1。

Code 檔案名稱：expression.cpp （exam/short/expression.cpp）

邏輯與手動追蹤

expr 迴圈處理 + -，呼叫 term；term 迴圈處理 * /，呼叫 unary。unary 讀數字、變數或括號；同級二元由左往右合併。eval 不接受變數；括號／一元鏈嵌套上限 256。

  • 100-30-1：先 100-30，再 -1，結果 69。
  • a+b*c：AST 是 (+ a (* b c))；postfix 是 a b c * +。
  • -2*-3：讀 2 → neg → 3 → neg → *，結果 6。
  • 2(3) 並非隱含乘法，會因多餘內容拒絕。

03 Scanner：沿用現有短程式

題目內容

Ch3 scanner / longest match 的延伸模擬題。教材 HW3 要擴充 ac 的 f/float、i/int、scientific number；本份是一般 C-like token 題，規格不同。

請對一份類 C 程式做詞彙分析，依序列出 keyword、identifier、number、string、char、operator 與 punctuation。忽略空白、單行 // 註解及非巢狀 /* */ 註解。先讀完整 identifier 再查保留字，operator 採最長匹配。quoted literal 中的註解符號不可當作註解，跳脫引號不得提早終止 literal。

輸入規格
整份 stdin 到 EOF；ID 可含底線；number 允許 .5、10.、e/E。keyword 名單及 operator 名單以檔案常數為準。
輸出規格
每個 token 一行：類型、空白、std::quoted 包裝的原始 lexeme；最後一行 EOF。
限制與適用範圍
不是完整 C/C++ lexer：沒有 preprocessing、raw string、數字 suffix 或完整字元 escape 語意；CHAR 只允許單 byte / 單簡單 escape。遇未閉註解／引號或非法 byte，exit 1 且 stdout 空。

07 Stack VM：沿用現有短程式

題目內容

Ch1 interpreter / Ch2 dc 產碼的延伸模擬題；指令名稱由本題定義，不是 GNU dc。

請執行 stack-based 虛擬機指令。PUSH number 把常數入 stack；STORE name pop 並保存；LOAD name 複製變數值。ADD/SUB/MUL/DIV 先取右 operand b，再取左 a，計算 a op b。NEG 取反，DUP 複製頂端，PRINT pop 並輸出。未知指令、未定義變數、underflow、零除或非有限值均視為錯誤。

輸入規格
每行一條指令到 EOF；空行忽略。PUSH/LOAD/STORE 恰有一個參數，其餘沒有參數；變數名採一般 ID 規則。

限制與適用範圍
long double，非任意精度；沒有跳躍、條件、函式或字串。EOF 可留未使用 stack；PRINT 與 dc p 的 pop 規則不同。

08 LL(1)：較低優先補充

題目內容

predict 的通用延伸模擬題；正式 FIRST/FOLLOW 術語預告於 Ch4，不能視為已確認 Ch1–3 考題。

給定 CFG，請計算各 nonterminal 的 FIRST / FOLLOW、各 production 的 SELECT，並建立 LL(1) 解析表。FIRST / FOLLOW 必須反覆傳播至固定點。RHS 可空時將 LHS 的 FOLLOW 加入 SELECT。同格若有多條 production，列出 conflict，判定非 LL(1)。無衝突時另可用 predictive stack 判定 token 序列。

輸入規格
先讀 P（1..1000），再讀 P 行 A -> X Y。每行只含一條 alternative；# 必須單獨表示 epsilon，$ 保留為 EOF。start 是第一個 LHS。--check 模式才讀其後每行空白分隔的 token sequence。
輸出規格
預設列 FIRST/FOLLOW/SELECT、非空表格 cell、CONFLICT 與 LL1 YES/NO。--check 每案印 ACCEPT/REJECT；不由字串原始字元自動 tokenize。
限制與適用範圍
不消除左遞迴、不做 left factoring，也不判定任意 CFG 是否無歧義；parse 步數 <=1000000。有 LL(1) conflict 時不任選規則繼續。

邏輯與手動追蹤

FIRST 與 FOLLOW 反覆合併至固定點；nullable RHS 將 FOLLOW 加進 SELECT。用 SELECT 填表，同格多條規則就是 conflict；解析用 stack 與 lookahead 查表。# 單獨代表 ε。

  • S -> a S | #：FIRST(S)={#,a}、FOLLOW(S)={$}。
  • SELECT(S->#)={$}，所以 EOF 時才選 epsilon，而不是看到任何字元都選。
  • A -> B C：若 C nullable，FOLLOW(A) 也要傳給 FOLLOW(B)。
  • 展開 S -> a S 時先 push S 再 push a，讓 a 先被處理。
